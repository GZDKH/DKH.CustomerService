### Границы проверки контактов (A7.1 / Customer57)

Четыре метода проверки email/телефона передают сценарии в Application через IContactVerificationUseCases. Авторизация, сопоставление вызывающего пользователя и выбор storefront остаются на входе. Сохранены сравнение с текущим контактом профиля, вызов существующего провайдера, ответы об ошибке/недоступности, отмена и запись подтверждённого состояния только после успеха. Прямой Application-порт сохраняет прежнюю границу вызовов провайдера относительно транзакции. Каноническое описание: [Architecture](../architecture.md#contact-verification-use-cases).
