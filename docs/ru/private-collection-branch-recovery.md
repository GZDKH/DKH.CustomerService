# Архив: восстановление ветки теста приватной коллекции

Локальная ветка `feat/6-private-collection-isolation` с коммитом
`d32934a264813dfa6a77848c0bffec5d52586945` сохранена как родитель этого
коммита восстановления. Тест приватной коллекции и исходный план позднее
вошли без изменений в коммит `e4541bc`, находящийся в main.

Сохранённая ветка также меняла версии двух центральных пакетов. Эти изменения
не входили в `e4541bc`; при восстановлении сохранены версии текущего main.
Исходная ветка доступна для проверки в истории родительского коммита.

Squash-слияние исключит исторического родителя. До squash или удаления
исходной ветки восстановления нужно отдельно сохранить оригинальный коммит.
